**Sangguniang Kabataan Financial Transparency & Governance Portal**

## 1. How to Log In

1. Open eSKala in your browser.
2. Click **Log In** on the navigation bar.
3. Enter your **email** and **password**, then click **Log In**.

> Don't have an account? Click **Register** to sign up as a Citizen.

## 3. What Can Each Role Do?

### 🛡️ Super Admin
- Create and manage all user accounts (Chairperson, Secretary, Treasurer, Citizen)
- Post, edit, and archive newsletters
- View full audit logs across all 18 barangays
- Switch between barangays using the header dropdown

### 👑 SK Chairperson
- Initiate and create new SK projects
- Review and approve or reject purchase orders submitted by the Treasurer
- Publish finalized projects to the public dashboard
- Reply to citizen comments and suggestions

### 📝 SK Secretary
- Draft and update project details
- Submit projects to the Treasurer for financial processing
- Reply to citizen comments and suggestions

### 💰 SK Treasurer
- Add itemized financial breakdowns to projects
- Create and manage purchase orders (physical and service types)
- Upload purchase order receipts (automatically scanned via OCR)
- Submit financial packages to the Chairperson for approval

### 🙋 Guest / Citizen
- Browse the public city dashboard and all 18 barangay dashboards
- View project details and financial breakdowns
- Submit comments and suggestions on projects
- Reply to existing comments
- Download project financial documents as ZIP archives

## 4. Project Approval Workflow

SK projects go through **5 stages** before they are published:

| Stage | Status | Who Acts |
| :--- | :--- | :--- |
| 1 | **Drafted** | Chairperson or Secretary creates the project |
| 2 | **Sent to Finance** | Chairperson or Secretary forwards to Treasurer |
| 3 | **Finance Update** | Treasurer adds purchase orders and receipts |
| 4 | **For Approval** | Treasurer submits back to Chairperson for review |
| 5 | **Posted ✅** | Chairperson approves — project goes live + newsletter auto-posts |

## 5. Navigating the System

| Where to Go | What You'll Find |
| :--- | :--- |
| **Home / Landing** | Overview of eSKala and quick access links |
| **Dashboard** | City-wide project and budget summary |
| **Barangay Pages** | Project data filtered by specific barangay |
| **Project Details** | Full budget breakdown, purchase orders, and comments |
| **SK Officials** | Directory of current and past SK officers |
| **Newsletter** | Public announcements and project highlights |
| **SK Home** | Role-specific dashboard for SK officials *(login required)* |
| **Super Admin Panel** | Account management and newsletter CRUD *(Super Admin only)* |
| **Audit Logs** | Activity and change history *(SK roles and Super Admin)* |

---

## 6. Super Admin — Switching Barangays

After logging in as Super Admin, use the **barangay dropdown in the top header** to switch between:
- **All-City Overview** — aggregate data across all 18 barangays
- Any specific barangay (e.g., Balibago, Tagapo, Sinalhan, etc.)
